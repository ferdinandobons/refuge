# Contributing to Refuge

Thank you for helping. Refuge is used in emergencies, so accuracy and clarity come before everything else.

## Content

- Every sentence of a card, guide or checklist must come from an official source (European guidelines, a national
  civil protection agency, ERC, IFRC, WHO…), cited next to it.
- Cards are generated by [tool/cards/cards.py](tool/cards/cards.py), the supplies catalogue by
  [tool/supplies/checklist.py](tool/supplies/checklist.py): edit those files, not the JSON, and run them again.
- Translations must say the same thing as the source, in plain words.

## Code

- Run `flutter analyze` and `flutter test` before opening a pull request.
- Open an issue before large changes.
